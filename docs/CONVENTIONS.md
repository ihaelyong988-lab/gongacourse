# CONVENTIONS (Rules) — 꽁아코스

> 누적 실전 규칙. 새 교훈은 여기 또는 `AGENTS.md` §4/§9에 1줄 추가(= 같은 설명 반복 방지). **확정 스펙·상세는 AGENTS.md §4/§9가 정본**, 본 문서는 요약.

## 구조/형식
- 빌드리스 정적 SPA: `index.html`(화면 6개+앱바+탭바) · `style.css` · `app.js`(5~20456줄 `defaultCourses` 304건 보존, 이후 로직).
- 화면 전환은 history 기반 스택 라우터(`navigate`/`showScreen`). 종료 confirm은 홈 최상단에서만.

## 스타일/품질
- **코스 이미지는 실사만**(키워드 매칭 loremflickr). 일러스트·이모지 금지.
- "사각도형나라" 금지 → 섹션 수평 라인 밴딩, 리스트는 박스 대신 hairline 행, 테두리는 `--hair`.
- 위계: 핵심 1개만 크게(예: 만보기 걸음수). 보조는 inline/별도 카드로 강등. 보라/핑크 그라데이션 회피, 그린 자연 팔레트.
- UI 작업은 **`ui-ux-pro-max` 스킬** 조회 후 적용(수동 추정 금지).

## 작업 방식 (사용자 지시 누적)
- 같은 지시 두 번 설명 요구 금지 — 첫 지시에 즉시 규칙화.
- 사용자가 특정 구성요소로 범위를 한정하면 그 구성요소의 DOM·스타일·진입 경로만 변경하고, 인접 화면은 출력 불변을 diff와 실제 화면으로 검증한다.
- "수납장/서랍"=아코디언 disclosure. "검색순"=인기검색 정렬(현재 라벨 "인기순"). "탭링크"=눈에 띄는 버튼. "간소화/직관"=필드 최소화+큰 버튼+가로배치.
- 추천 코스는 현재 계절+날씨 연동 필수. 외부 API는 무료·키불필요·CORS·폴백.
- 솔직한 한계 고지(예: 웹 만보기 백그라운드 미작동). 단, 한계 안에서 **실해결책은 끝까지 찾는다**: 만보기 끊김 = 화면 꺼짐이 근본원인 → 측정 중 `navigator.wakeLock`(Screen Wake Lock)으로 화면을 안 꺼지게 잡음(secure context/HTTPS 필수, 미지원·거부는 graceful). 전원버튼 강제 OFF·완전 백그라운드만 원리적 불가(네이티브 전용)로 남기고 정직 고지.
